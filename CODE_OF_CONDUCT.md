# Code of Conduct

## Our pledge and standards

`lean-no-comments` adopts the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html). Everyone participating in `lean-no-comments`—human contributors, reviewers, the maintainer, and anyone directing an AI agent—is expected to keep the project welcoming and harassment-free.

- Direct technical, mathematical, and scientific criticism at the work (the specification, theorem, proof, algorithm, claim, or document), never at the person.
- Be respectful of differing viewpoints and experiences, and accept constructive criticism of claims, proofs, and designs.
- Do not engage in harassment, personal or political attacks, trolling, insulting or derogatory comments, sexualized language or imagery, or publishing others' private information without explicit permission.

## Scope

This Code of Conduct applies in all spaces managed by the `lean-no-comments` project on GitHub ([issues](https://github.com/rbeauchamp/lean-no-comments/issues), [pull requests](https://github.com/rbeauchamp/lean-no-comments/pulls), reviews, comments, and discussions when enabled) and whenever someone represents the project in public.

## Reporting and enforcement

`lean-no-comments` is maintained by Richard Beauchamp ([@rbeauchamp](https://github.com/rbeauchamp)).

Report unacceptable behavior privately through [GitHub's private reporting for rbeauchamp/lean-no-comments](https://github.com/rbeauchamp/lean-no-comments/security/advisories/new) (Security → Advisories → Report a vulnerability, which reaches only the repository owner; see [SECURITY.md](SECURITY.md) and [CONTRIBUTING.md](CONTRIBUTING.md)). Reports are handled confidentially.

To enforce these standards, the maintainer may warn a participant, edit, remove, or close comments, issues, commits, or pull requests that violate this Code of Conduct, or temporarily or permanently block an account from the repository.
