## Blind Second-Model Comparison (`BlindSecondModel.lean` and `Comparison.lean`)

`BlindSecondModel.lean` formalizes an independent reading of the owner-level specification, and `Comparison.lean` compares both formalizations inside Lean:

- **Equivalent under full contracts (`Comparison.lean`):** **Proved** exact `Meets` equivalence (`isFingerprint_meets_iff`, `fingerprint_meets_iff`, `firstOutOfOrder_meets_iff`, `sortFingerprints_meets_iff`, `missingFrom_meets_iff`, `sourceOrder_meets_iff`, `checkExactSync_meets_iff`, `checkMonotonicFile_meets_iff`) plus conditional equivalence when 1-based line numbers hold (`distinctLines_equiv_of_pos`, `analyzeComments_equiv_of_pos`) and when `analyses` has distinct `.file` keys (`validateCheck_equiv_of_nodup`).
- **Six formalized divergences (`Comparison.lean`):**
  - `diff_distinctLines_zero_line`: Synthetic `startLine = 0` is clamped via `max 1 c.startLine` by `BlindSecondModel.coveredLines` (`1` line) while `CoreSpec.DistinctLines` counts `[0, 1]` (`2` lines); real `FileMap` positions are 1-based.
  - `diff_validateCheck_duplicate_file`: Duplicate `FileAnalysis` entries for the same file fail under `RatchetSpec.ValidateOk` (`Array.find?` inspects the first match) while `BlindSecondModel.ValidCheck` checks `∃ a ∈ analyses` and passes when a later duplicate has zero comments; real `Runner` collects one analysis per unique tracked file.
  - `diff_collectRanges_plainDocComment`: `CoreSpec.docKind` includes `Lean.Parser.Command.plainDocComment` in addition to `docComment` and `moduleDoc`, whereas `BlindSecondModel.docKind` omitted `plainDocComment`.
  - `diff_classifyFile_segmentPrefix`: `ConfigSpec.PrefixMatches` matches on `/` path-segment boundaries (`"Foo"` does not match `"FooBar.lean"`), whereas `BlindSecondModel.Classification` used `String.startsWith`.
  - `diff_parseConfig_cleanCtrl`: `ConfigSpec.cleanStr` forbids `\n`, `\r`, `\t`, `\x00`, and `\\`, whereas `BlindSecondModel.CleanText` forbids all ASCII control chars `< 32` and `127` (`\x01` accepted vs. refused).
  - `diff_checkToken_identMismatch`: `CoreSpec.literalToken` round-trips identifier spelling through `Lean.Parser.tokenFn` (refusing a forged `.ident` whose raw slice is `"--"`), whereas `BlindSecondModel.LiteralAt` accepted any `.ident` constructor unconditionally.
